### Gradient Boosting 성능 개선 단계별 기여

| 단계 | 내용 | R² | 증가 |
|---|---|---:|---:|
| S0 | 기본 GB (전체 1,460건) | 0.8079 | — |
| **S1** | **이상치 2건 제거** | **0.8954** | **+0.088** |
| S2 | 파생변수 8종 | 0.8997 | +0.004 |
| S3 | TargetEncoder | 0.8994 | -0.000 |
| S4 | 하이퍼파라미터 튜닝 | **0.9041** | +0.005 |

전체 개선폭 **+0.096 중 92%가 S1(이상치 2건 제거)** 에서 나왔다.
과적합 갭(Train R² − Test R²)은 0.144 → 0.062로 **감소** — 성능 상승이 과적합이 아님을 확인했다.

## 분석에서 밝혀낸 것

채점 기준에 "근거 없는 결과 서술" 감점 항목이 있다.
아래는 **결과를 그대로 받아쓰지 않고 근거를 파고들어 얻은** 다섯 가지다.

### ① 이상치 2건의 정체 — SaleCondition = Partial

과제 1에서 "품질 10등급인데 시세 절반"인 주택 2채(`Id 524`, `Id 1299`)를 발견했다.
원본 81컬럼 데이터로 대조한 결과:

| | Id 524 | Id 1299 |
|---|---|---|
| SaleCondition | **Partial** (미완성 상태 부분매매) | **Partial** |
| 평당가 | $39.5 | $28.4 |
| 지역 | Edwards (중앙값 $122K · 1,200sqft) | 동일 |
| 면적 | 4,676 sqft | 5,642 sqft |

전체 평당가 중앙값이 $120인데 그 **1/3~1/4 수준**이다.
기록된 가격이 완성 주택의 시장가가 아니라 **미완성 건물의 거래가**이며,
감축본 16개 feature에는 `SaleCondition`이 없어 모델이 정상 거래와 구별할 방법이 없다.
데이터셋 원저자 **De Cock(2011)도 `GrLivArea > 4000` 관측치 제거를 권고**한다.

→ 이 2건(전체의 0.14%)을 제거하니 **R² 0.808 → 0.895**.

### ② CentralAir 7.21배는 인과가 아니라 교란(confounding)

Power BI Key Influencers가 "중앙냉방 있음"을 1위 요인(7.21배)으로 뽑았다.
그대로 서술하면 "냉방을 설치하면 7배 비싸진다"는 틀린 결론이 된다.

| | CentralAir = N | CentralAir = Y |
|---|---:|---:|
| 건수 | 95건 (6.5%) | 1,365건 |
| High 비율 | 7.37% | 53.11% |
| **건축연도 중앙값** | **1925년** | 1976년 |
| 1950년 이전 건축 | **81%** | 18% |
| OverallQual 평균 | 4.67 | 6.20 |

중앙냉방은 1970년대 이후 신축의 표준 사양이므로,
`CentralAir = N`은 사실상 **"1950년 이전에 지은 노후 주택"의 대리 변수(proxy)** 다.
가격을 낮추는 진짜 원인은 노후·저품질·소형이다.
(배수 검산: 53.11% ÷ 7.37% = 7.21 — 화면 수치와 일치)

### ③ Orange kNN만 R² 0.634로 폭락 (sklearn 0.8195)

Orange의 kNN 위젯은 기본적으로 입력을 표준화하지 않는다.
그 결과 `LotArea`(수천~수만 단위)가 유클리드 거리 계산을 독점하고,
설명력이 가장 높은 `OverallQual`(1~10)의 기여가 묻힌다.
문제지 부록의 "kNN·SVM은 스케일링 여부에 민감"을 실증한 사례다.
트리 계열은 Orange/sklearn 차이가 0.005 이내로, 스케일링이 원인이라는 설명과 정합한다.

### ④ 로그 변환은 평가 지표에 따라 결론이 뒤집힌다

| Model | 타깃 | R² | MAE |
|---|---|---:|---:|
| Linear | 원본 | 0.7943 | 21,373 |
| Linear | log1p | **0.5053** | **19,417** |
| RF | 원본 | 0.8286 | 18,622 |
| RF | log1p | **0.8404** | 18,823 |

로그 공간에서 최적화하면 상대오차는 줄지만 역변환 시 고가 주택의 절대오차가 증폭된다.
**"왜도가 크면 로그 변환"이라는 통념이 이 데이터에서는 성립하지 않는다.**

### ⑤ Linear ≈ Ridge — 다중공선성 제거의 독립적 증거

`RidgeCV`로 alpha를 0.01~1000 범위에서 탐색해도 선택값이 0.11(최소 근처)이고
R²는 Linear과 소수점 4자리까지 동일(0.7881)했다.
Ridge는 공선성으로 인한 계수 불안정을 L2 규제로 억제하는 모델인데 개입 여지가 없다는 뜻이며,
**과제 2의 VIF 제거가 유효했다는 독립적 증거**가 된다.

## 시각화 원칙

전 산출물(파이썬 7종 · HTML 3종 · Power BI 5종)에 동일한 색 언어를 적용했다.

| 색 | 코드 | 의미 |
|---|---|---|
| 회색 | `#C8CDD3` | 일반 데이터 (맥락) |
| 남색 | `#1F4E79` | 핵심 강조 |
| 빨강 | `#B94A48` | 이상치 · 주의 |

- 범주마다 다른 색을 쓰는 무지개 팔레트 전면 제거 (순서형 변수는 **단일 색조 그라데이션**)
- 제목은 차트 종류가 아니라 **데이터에서 확인된 결론**을 서술
  (예: "박스플롯" → "품질 7→8 구간에서 가격 중앙값 35% 급등")
- 제목의 모든 수치는 코드가 계산한 값을 f-string으로 주입 — 하드코딩 없음
- 표본이 적은 범주는 강조에서 제외하고 회색 라벨 처리 (예: Blueste n=2)
