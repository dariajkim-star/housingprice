# 과제 4. Power BI 시각 개체 5종 [15점]

## 무엇을
Power BI Desktop으로 `data/housePricing_selected.csv`(과제 2 결과물)를 적재하고 서로 다른 시각 개체 5종으로 보고서 1페이지를 구성.

## 어떻게 — 단계별

### 1) 데이터 적재
1. Power BI Desktop 실행 → **데이터 가져오기 > 텍스트/CSV**
2. `C:\Users\user\Desktop\수업내용정리\260731\housingprice\data\housePricing_selected.csv` 선택
3. 파일 원본 = **65001: 유니코드(UTF-8)** 확인 (한글 깨짐 방지 — 공통 감점 항목)
4. **데이터 변환**에서 쿼리 이름을 `data` 로 변경 → **닫기 및 적용**
5. 데이터 형식 확인: SalePrice·GrLivArea·LotArea·TotalBsmtSF = 정수, OverallQual·GarageCars·FullBath·Fireplaces = 정수, YearBuilt·YearRemodAdd = 정수(날짜 아님), Neighborhood·ExterQual·KitchenQual·CentralAir = 텍스트

### 2) 계산 열 미리 생성 (과제 5로 바로 연결)
테이블 도구 > **새 열**:
```dax
SalePrice_등급 =
IF ( 'data'[SalePrice] >= MEDIANX ( ALL ( 'data' ), 'data'[SalePrice] ), "High", "Low" )
```
측정값(카드용):
```dax
평균 SalePrice = AVERAGE ( 'data'[SalePrice] )
주택 수 = COUNTROWS ( 'data' )
최고 SalePrice = MAX ( 'data'[SalePrice] )
```

### 3) 시각 개체 5종

| # | 시각 개체 | 필드 배치 | 용도 설명 |
|---|---|---|---|
| ① | **카드(Card)** ×3 | `평균 SalePrice` / `주택 수` / `최고 SalePrice` | 전체 시장 규모와 평균 가격 수준을 한눈에 보여주는 KPI. 슬라이서와 연동돼 필터 상황을 즉시 반영. |
| ② | **묶은 세로 막대형** | X축=`Neighborhood`, Y축=`평균 SalePrice`, 정렬=Y축 내림차순 | 지역별 가격 서열을 비교. NoRidge·NridgHt·StoneBr 상위 vs MeadowV·IDOTRR 하위로 3.4배 격차를 드러냄. |
| ③ | **분산형(산점도)** | X축=`GrLivArea`, Y축=`SalePrice`(요약 안 함), 범례=`OverallQual` | 면적-가격의 양의 선형관계(r=0.71)를 보여주고, 색(품질)으로 같은 면적에서도 품질이 가격을 끌어올림을 확인. |
| ④ | **꺾은선형** | X축=`YearBuilt`, Y축=`평균 SalePrice` | 건축연도별 평균가 추이. 최근 건축일수록 우상향하는 신축 프리미엄을 확인. |
| ⑤ | **슬라이서** | 필드=`Neighborhood` (드롭다운) + `OverallQual` (범위 슬라이더) | 지역·품질 조건을 바꿔가며 위 4개 시각 개체를 상호작용 필터링. |

> 산점도에서 `SalePrice` 필드를 끌어놓으면 기본이 **합계**이므로, 필드 우클릭 → **요약 안 함**으로 반드시 변경해야 1460개 점이 개별로 찍힌다.

## 4) 시각화 색 규칙 — 과제 1·2·3과 통일

Power BI 기본 팔레트(밝은 파랑 `#118DFF`)는 파이썬 차트와 톤이 달라 보고서가 따로 논다.
아래 3단계로 **회색 기본 / 남색 강조 / 빨강 이상치** 규칙을 Power BI에도 적용한다.

| 색 | 코드 | 용도 |
|---|---|---|
| 남색 | `#1F4E79` | 핵심 강조 (전달하려는 메시지) |
| 회색 | `#C8CDD3` | 일반 데이터 (맥락) |
| 진회색 | `#7B8794` | 산점도 등 밀집 데이터 |
| 빨강 | `#B94A48` | 이상치·주의 (남용 금지) |

### STEP A. 테마 적용 (전체 톤 일괄 변경)
1. 상단 **보기** 탭 → **테마** 드롭다운 → **테마 찾아보기**
2. `04_powerbi/mckinsey_theme.json` 선택
3. 적용 즉시 전체 시각 개체가 남색/회색 계열 + Malgun Gothic + 왼쪽 정렬 제목 + 얇은 격자로 바뀐다

### STEP B. 지역별 막대 — 강조/비강조 분리 (조건부 서식)
테마만으로는 모든 막대가 같은 남색이 된다. **상위 지역만 남색, 나머지는 회색**으로 만들려면:

1. `dax_measures.txt` 의 **`지역색_상위3`** (또는 `지역색_평균이상`) 측정값을 만든다
   (모델링 탭 → 새 측정값 → 붙여넣기)
2. 막대 차트 선택 → **서식(붓 아이콘)** → **막대** → **색** 항목의 오른쪽 **`fx`** 클릭
3. **서식 스타일 = "필드 값"** 선택 → **필드**에 방금 만든 측정값 지정 → 확인

| 측정값 | 강조 대상 | 특징 |
|---|---|---|
| `지역색_상위3` | 평균가 상위 3개 (NoRidge·NridgHt·StoneBr) | 메시지가 가장 선명 |
| `지역색_평균이상` | 전체 평균 이상 **AND** 표본 20건 이상 | 과제 1 ④번 파이썬 차트와 동일 규칙 |

> `지역색_평균이상`을 쓰면 Veenker(표본 11건)·Blueste(2건)처럼 **평균이 불안정한 지역이 강조에서 빠진다.**
> 과제 1 README의 "표본 20건 미만 6곳" 주의사항과 같은 처리다.

### STEP C. 산점도 — 무지개 제거
문제지가 "**OverallQual 로 색상 구분**"을 요구하므로 색 구분 자체는 유지해야 한다.
그런데 `OverallQual`을 **범례**에 넣으면 Power BI 기본 팔레트가 10개 등급에 노랑·빨강·초록·보라를
차례로 배정해 무지개가 된다.

> ⚠️ 분산형 차트에는 **색 채도(Color saturation) 칸이 없다.** (맵·트리맵 등 일부 시각 개체 전용)
> 따라서 범례를 유지한 채 **색상 순서 자체를 청색 그라데이션으로 바꾸는 방식**을 쓴다.

**방법 1 — 테마로 자동 처리 (권장)**
`mckinsey_theme.json` 의 `dataColors` 앞 10개를 **연한 파랑 → 진한 남색 램프**로 정의해 두었다.

```
#DCE6EF → #C3D4E5 → #AAC2DB → #91B0D1 → #789EC7
       → #5F8CBD → #4A7BA7 → #376391 → #2A567F → #1F4E79
```

범례 항목은 값 순서대로 이 색을 받으므로, **품질 1은 가장 연한 파랑, 품질 10은 가장 진한 남색**이 된다.
STEP A에서 테마를 적용했다면 산점도는 자동으로 이렇게 바뀐다. 별도 조작이 필요 없다.
(막대·꺾은선은 `visualStyles`에서 남색 `#1F4E79`로 따로 고정해 두어 램프의 영향을 받지 않는다)

**방법 2 — 수동 지정 (테마를 못 쓸 때)**
산점도 선택 → 서식(붓) → **데이터 색** → 범례 값 10개가 각각 색 선택기로 나온다.
위 램프 색상 코드를 품질 1~10 순서대로 직접 입력한다.

결과: 품질이 낮을수록 연한 파랑, 높을수록 진한 남색인 **단일 색조 순차 스케일**이 된다.
요구사항("OverallQual로 색상 구분")을 충족하면서, 색이 곧 순서 정보를 담아 범례를 보지 않아도 읽힌다.
과제 6·7 HTML 대시보드의 산점도와도 같은 방식이다.

### STEP D. 카드·꺾은선
테마가 자동 처리한다 (카드 숫자 남색 34pt, 꺾은선 남색 2px).
꺾은선에서 2000년 이후 구간만 강조하고 싶으면 `연도색_2000년대` 측정값을 STEP B와 같은 방식으로 적용한다.
